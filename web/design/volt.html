Your palette, mapped into a semantic system. The one deliberate move: three of your five colors sit exactly on status hues — so instead of fighting that, they become the status system. Teal = success. Orange = warning. Purple = the brand. And the volt yellow is reserved as the signature — it never means anything except alive.

The mapping — your five colors → roles

#92278Faccent — buttons, links, selection, focus. Far from every status hue, so it owns "interactive" cleanly.
#E3FF00volt — the signature. Live-presence pulse, realtime highlights, marker emphasis, the logo beam. Never semantic, only energy. (Light theme uses #C6DF00 so it survives on white.)
#01A79Esuccess — done states, healthy, confirmations.
#FF6A00warning — rate-limit toasts, unsaved changes, expiring sessions.
#000000ink & frame — text and the hard 2px borders that give it the poster feel. Surfaces sit at #0C0C0E in dark (pure black smears on OLED); pure black stays for shadows and frames.
+ #DC2626danger — the one color your palette was missing. Destructive actions need red; nothing else may use it.

Type — the cooler font

Archivo Black — display
Space Grotesk for UI and body — geometric, techy, easy at 14px. Exactly the poster's voice, self-hosted via @fontsource so the app makes zero font requests to third parties.
JetBrains Mono → counts, IDs, timestamps, keyboard hints
